## Controls
| Action | Input |
|---|---|
| Move forward/backward | Arrow keys / WASD |
| Jump / Double jump | Space |
| Attack | Left mouse click |
| Pause menu | Escape |
| Select in menu | Enter / E / Left mouse click |

## Download & Play
Go to [Releases](../../releases) to download the executable.
No installation required — just unzip and run.
